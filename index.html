Three steps, one ready-to-use panel

No manual reverse proxy or certificate setup required.

01

Run the installer

A single command on a fresh Debian/Ubuntu VPS. Docker, Go, Nginx and the HTTPS certificate are all handled automatically.

02

Create your admin account

An identity that belongs to the panel, separate from your SSH/root access. Add more accounts later — each user only ever sees their own apps.

03

Deploy your first app

From a public GitHub repo, a private repo you've connected, or a .zip archive. VPS Control detects the stack and builds the container for you.

Everything you need, nothing you don't

A single Go binary, no heavy dependency for the panel itself.

👥

Multi-user with strict isolation

Create admin and read-only accounts. Every user sees only their own apps and servers — even panel admins can't reach another user's apps unless invited as a collaborator.

🖥️

Per-user servers with quotas

Admins create logical servers (disk quota, max apps) and assign them to users, Pterodactyl-style. Quotas are enforced on deployment — a user can't exceed their limit.

🐙

GitHub integration

Connect your GitHub account with a Personal Access Token to list and deploy private repositories and organization repos, directly from the panel.

📁

File manager

Browse, edit, upload and delete files straight from the browser — no more SFTP client.

🐳

Docker services

Start, stop, restart or remove your containers with one click, and check their logs live.

🚀

One-click deployment

From a public GitHub repo, a private one, or a .zip archive — with automatic stack detection (Laravel, Node, Python, static) and automatic subfolder detection.

🌐

Custom domains & SSL

Point any domain at an app's port and get it reverse-proxied through Nginx with a free Let's Encrypt certificate — straight from the web panel.

🗄️

Database browser

Connect a MySQL or PostgreSQL database, browse tables, edit rows, run free-form SQL queries.

🧹

Clean cascade deletion

Deleting a user or a server removes everything: containers, images, folders, backups, Nginx vhosts and SSL certificates. A preview shows you exactly what will be removed.

🔄

Built-in updates

A button in the panel (or a daily timer, if you enable it) pulls, rebuilds and restarts from GitHub.

Install with a single command

On a fresh Debian/Ubuntu VPS. Docker, Go and Nginx are installed automatically if needed.

curl -fsSL https://install.vpscontrol.wazestudio.com | sudo bash

The installer asks for your domain, then obtains an HTTPS certificate via Let's Encrypt (Certbot) — it will ask its own usual questions (email, terms of service) itself.

curl -fsSL https://install.vpscontrol.wazestudio.com | sudo bash

Just press Enter at the domain question: the panel becomes available over HTTPS via the VPS's IP and a port of your choice (self-signed certificate).

Why VPS Control?

  • 100% open source — the code is yours, hosted on your own VPS.
  • No monthly fee, no third-party account required.
  • Docker isolation: every deployed application runs in its own container.
  • Real multi-user: admins manage users and servers; users only see their own apps.
  • Quota-enforced servers, so a VPS shared with teammates stays under control.
  • Native GitHub integration: deploy public and private repos without leaving the panel.
  • Built for small VPS instances: no Node/PHP/JVM to run for the panel itself.
  • Easy to audit: a handful of Go files on the backend, a framework-free JS frontend.
