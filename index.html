Tout ce qu'il faut, rien de superflu

Un seul binaire Go, aucune dépendance lourde pour le panel lui-même.

📁

Gestionnaire de fichiers

Parcourez, éditez, uploadez et supprimez des fichiers directement depuis le navigateur — plus besoin de client SFTP.

🐳

Services Docker

Démarrez, arrêtez, redémarrez ou supprimez vos conteneurs d'un clic, et consultez leurs logs en direct.

🚀

Déploiement en un clic

Déployez depuis un dépôt GitHub public ou une archive .zip. Détection automatique du stack (Laravel, Node, Python, statique).

🗄️

Navigateur de bases de données

Connectez une base MySQL ou PostgreSQL, parcourez les tables, éditez les lignes, exécutez des requêtes SQL libres.

🔐

Comptes admin dédiés

Identifiants propres au panel, séparés du SSH/root du serveur. Multi-comptes admin ou lecture seule.

🪶

Vraiment léger

Un binaire Go unique, stockage JSON local, pas de base de données à faire tourner pour le panel. Confortable dès 2 Go de RAM.

Installation en une commande

Sur un VPS Debian/Ubuntu fraîchement installé. Docker et Go sont installés automatiquement si besoin.

curl -fsSL https://install.vpscontrol.lordobitotech.xyz | sudo bash

Avec un nom de domaine pour du HTTPS automatique :
curl -fsSL https://install.vpscontrol.lordobitotech.xyz | sudo bash -s -- panel.mondomaine.com

Pourquoi VPS Control ?

  • 100% open source — le code vous appartient, hébergé sur votre propre VPS.
  • Aucun frais mensuel, aucun compte tiers requis.
  • Isolation par Docker : chaque application déployée tourne dans son propre conteneur.
  • Pensé pour les petits VPS : pas de Node/PHP/JVM à faire tourner pour le panel.
  • Simple à auditer : un backend Go d'une poignée de fichiers, un frontend JS sans framework.
