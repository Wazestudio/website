Trois étapes, un panel prêt à l'emploi

Aucune configuration manuelle de reverse proxy ou de certificat à prévoir.

01

Lancez l'installeur

Une seule commande sur un VPS Debian/Ubuntu vierge. Docker, Go, Nginx et le certificat HTTPS sont pris en charge automatiquement.

02

Créez votre compte admin

Un identifiant propre au panel, séparé de vos accès SSH/root. Ajoutez d'autres comptes ensuite si besoin.

03

Déployez votre première app

Depuis un dépôt GitHub public ou une archive .zip. VPS Control détecte le stack et construit le conteneur pour vous.

Tout ce qu'il faut, rien de superflu

Un seul binaire Go, aucune dépendance lourde pour le panel lui-même.

📁

Gestionnaire de fichiers

Parcourez, éditez, uploadez et supprimez des fichiers directement depuis le navigateur — plus besoin de client SFTP.

🐳

Services Docker

Démarrez, arrêtez, redémarrez ou supprimez vos conteneurs d'un clic, et consultez leurs logs en direct.

🚀

Déploiement en un clic

Depuis un dépôt GitHub public ou une archive .zip, avec détection automatique du stack (Laravel, Node, Python, statique).

🗄️

Navigateur de bases de données

Connectez une base MySQL ou PostgreSQL, parcourez les tables, éditez les lignes, exécutez des requêtes SQL libres.

🔐

Comptes admin dédiés

Identifiants propres au panel, séparés du SSH/root du serveur. Multi-comptes, admin ou lecture seule.

🔄

Mises à jour intégrées

Un bouton dans le panel (ou un minuteur automatique quotidien, si vous l'activez) recompile et redémarre depuis GitHub.

Installation en une commande

Sur un VPS Debian/Ubuntu fraîchement installé. Docker, Go et Nginx sont installés automatiquement si besoin.

curl -fsSL https://install.vpscontrol.wazestudio.com | sudo bash

L'installeur vous demande votre domaine, puis obtient un certificat HTTPS via Let's Encrypt (Certbot) — il vous posera lui-même les questions habituelles (email, conditions d'utilisation).

curl -fsSL https://install.vpscontrol.wazestudio.com | sudo bash

Répondez simplement Entrée à la question du domaine : le panel sera accessible en HTTPS via l'IP du VPS et un port de votre choix (certificat auto-signé).

Pourquoi VPS Control ?

  • 100 % open source — le code vous appartient, hébergé sur votre propre VPS.
  • Aucun frais mensuel, aucun compte tiers requis.
  • Isolation par Docker : chaque application déployée tourne dans son propre conteneur.
  • Pensé pour les petits VPS : pas de Node/PHP/JVM à faire tourner pour le panel.
  • Simple à auditer : un backend Go d'une poignée de fichiers, un frontend JS sans framework.
